For the last few months I’ve been building a software factory: a set of AI agents that plan, write, test, review and release software while I set the goals. Some of what it builds is for my own house and family, and some I build with friends. Some of it turned out to be useful to other people, so it needed a home.

> A windfall is the fruit that drops before anyone picks it. It’s free, and it’s usually good.

This page is that home. Each app is small and does one job, and each one gets the same checks a professional team would give it. You can read how I think about that, and about what “free” means here, on the [principles page](/principles/).
